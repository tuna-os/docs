# Switch to Bazzite: unlisted preview

`src/pages/switch-to-bazzite.tsx` renders this component at `/switch-to-bazzite`.
It is the home page for the Bazzite build of wootc
(`Bazzite-Installer.exe`).

## Status: unlisted preview

Universal Blue owns the Bazzite mark and name. They have not approved this use
yet: wootc `app/branding/bazzite/blessing.json` is `status: pending`,
`ask.filed: false`. Until they say yes, the page stays unlisted:

- no link from the navbar, the footer, a sidebar, `src/data/` or any other page;
- `<meta name="robots" content="noindex, nofollow">` on the page;
- an `X-Robots-Tag: noindex, nofollow` header from `static/_headers`;
- `ignorePatterns` in the sitemap options of `docusaurus.config.ts`;
- `ignoreFiles` in the local search options of `docusaurus.config.ts`;
- a preview banner at the top of the page.

Do not add a `robots.txt` `Disallow` for the route: a crawler that obeys it
never fetches the page, so it never sees the `noindex`.

To publish after a yes, first record the yes in wootc `blessing.json`. Then
remove the banner, the robots meta, the `_headers` rule and the two config
entries. Then link the page from `src/data/`.

## Test status

`BAZZITE_STATUS` at the top of `index.tsx` selects the status line. Change it
from `'testing'` to `'proven'` when wootc `docs/status.md` shows a green E2E
cell for the Bazzite build. Then update the `proven` text with the run link.
