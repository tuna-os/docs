# TunaOS Flatpaks

Install TunaOS applications from our Flatpak remote.

## 1. Add the remote

This is a one-time step:

```bash
flatpak remote-add --if-not-exists tuna-os https://tunaos.org/flatpak/tuna-os.flatpakrepo
```

## 2. Install apps

Everything below is installable from the remote. See the [App Guide](/docs/flatpak/guide) for the full catalog (13 apps, including system tools and the live-ISO installer frontends).

Office suite (pure Rust on GTK4 — no Python or WebKit dependency):

<Tabs>
  <TabItem value="tables" label="🧮 Tables">
    ```bash
    flatpak install tuna-os org.tunaos.tables
    ```
  </TabItem>
  <TabItem value="decks" label="🎬 Decks">
    ```bash
    flatpak install tuna-os org.tunaos.decks
    ```
  </TabItem>
  <TabItem value="letters" label="📄 Letters">
    ```bash
    flatpak install tuna-os org.tunaos.letters
    ```
  </TabItem>
</Tabs>

Or install all three at once:

```bash
flatpak install tuna-os org.tunaos.tables org.tunaos.decks org.tunaos.letters
```
