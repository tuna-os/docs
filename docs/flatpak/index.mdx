# TunaOS Flatpaks

Install GNOME office apps directly from our Flatpak remote.

## 1. Add the remote

This is a one-time step:

```bash
flatpak remote-add --if-not-exists tuna-os https://tunaos.org/flatpak/tuna-os.flatpakrepo
```

## 2. Install apps

Pure Rust GTK4 apps — no Python or WebKit dependency.

<Tabs>
  <TabItem value="tables-rust" label="🧮 Tables">
    ```bash
    flatpak install tuna-os org.tunaos.tables-rust
    ```
  </TabItem>
  <TabItem value="decks-rust" label="🎬 Decks">
    ```bash
    flatpak install tuna-os org.tunaos.decks-rust
    ```
  </TabItem>
  <TabItem value="letters-rust" label="📄 Letters">
    ```bash
    flatpak install tuna-os org.tunaos.letters-rust
    ```
  </TabItem>
</Tabs>

Or install all three at once:

```bash
flatpak install tuna-os org.tunaos.tables-rust org.tunaos.decks-rust org.tunaos.letters-rust
```
