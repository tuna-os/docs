# Community

Welcome to the TunaOS community! Whether you are a user, contributor, or curious, here is how to participate.

## Donate AI CLI time

**[Lend your AI CLI through Hive](https://hub.tunaos.org/#contribute)** — no code needed.

Hive coordinates AI coding agents across TunaOS's two official hives: **School** for OS and builds, and **Reef** for apps. The setup on the hub starts one ClankeR relay and runs one task at a time. It alternates eligible hives after each task. If one is empty or unavailable, the other continues. `hive.tunaos.org` is School's alias, not a third hive.

You use a local, signed-in AI CLI and a container. Your provider's subscription quota or API charges apply. The guide explains the prerequisites, credential and container limits, and how to stop with Ctrl+C. Keep account secrets and API keys private; never send them to maintainers.

## How to Contribute

See the full [Contributor Guide](https://github.com/tuna-os/tunaOS/blob/main/CONTRIBUTING.md) for setup instructions and PR workflow.

| Level | What you do | How to start |
|---|---|---|
| **Tester** | Run images, report bugs | Install any variant, open issues |
| **Contributor** | Fix bugs, improve docs | Pick a [starter issue](https://github.com/issues?q=org%3Atuna-os+is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22), open PRs |
| **Maintainer** | Own a desktop flavor or variant | Build regularly, review PRs, earn trust |

All contributors must follow our [Code of Conduct](https://github.com/tuna-os/tunaOS/blob/main/CODE_OF_CONDUCT.md).

## Contribution Pathways

The [Contributor Hub](/docs/contributing-hub) lists every TunaOS project by work type. Each row links to that project's
`CONTRIBUTING` page and names the work it does. It also points to the live
list of good first issues across the org.

Start there to find a project that matches your skills. Then return to this
page to join the chat, or open an issue to propose a change.

## Adoption

If your organization uses TunaOS, we'd love to know!

- Add your org to **[ADOPTERS.md](https://github.com/tuna-os/tunaOS/blob/main/ADOPTERS.md)** — open a PR
- Share your setup in [GitHub Discussions](https://github.com/tuna-os/tunaOS/discussions)
- Write a case study or blog post (we'll help promote it!)
