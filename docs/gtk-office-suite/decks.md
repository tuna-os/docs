# 📽️ Decks — quick start

Decks is the presentation app (`decks-core`). Install it first — see the
[Office Suite overview](./index.md#-quick-install) — then come back here.

## Create or open a presentation

- **New**: launch Decks, or open a new tab from the header bar.
- **Open**: the file picker accepts **`.pptx`** and **`.odp`**.
- **Save**: `app.save-file-as` — same two formats as open.

## Building slides

The slide list on the side is where you navigate and reorder slides.
Click a slide to edit it, or use the prev/next controls to step through.

| What | Action |
|---|---|
| Add a text box | `app.add-text-box` |
| Add a shape | `app.add-shape` |
| Add an image | `app.add-image` |

As in the other two apps, the full action list with shortcuts is in the
command palette (**Ctrl+K**) and the shortcuts overlay (**Ctrl+?**).

## Speaker notes

Each slide has its own notes field in the main window. Select a slide and
type in the notes area to attach speaker notes to it. Notes round-trip
through both `.pptx` and `.odp`.

## Present

**`app.present`** starts presentation mode from the current slide.
