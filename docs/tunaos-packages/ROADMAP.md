## Mission

Own the native packaging, patches, build ordering, validation, signing, and
publication work needed to ship curated desktop stacks for TunaOS variants —
independently of third-party repositories. The active production chain is the
native EL10 RPM build for GNOME and XFWL4, published via GitHub Actions +
Mock to Cloudflare R2 (COPR is bootstrap/compatibility only, being retired).

---

## Current Status (August 2026)

- **GNOME 51 packaging kicked off for EL10** (08-10) — build-order-gnome51.yml active.
- **XFWL4 ported to Debian/Ubuntu manifests** (08-10) — cross-base parity work started.
- **Desktop parity audit is the top risk**: [tunaos-packages#133](https://github.com/tuna-os/tunaos-packages/issues/133)
  found **24 of 37 published editions are too small to contain their desktop**
  (non-RPM bases: sailfin/flounder/grouper ship +0.16–0.33 GB desktop deltas vs
  +0.7–2.5 GB healthy). Every image has exactly 65 layers, so layer count masks
  the problem. Tracks upstream on [tunaos#1294](https://github.com/tuna-os/tunaos/issues/1294).
- COPR migration to GitHub/R2 in progress; native GNOME EL10 specs stay until
  the R2 pipeline passes build + staged-install + desktop runtime gates.
