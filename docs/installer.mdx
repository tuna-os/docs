# Install TunaOS

import InstallerWalkthrough, {numberedSteps} from '@site/src/components/InstallerWalkthrough';

The computer started from the USB stick, and TunaOS shows its desktop. The
installer opens automatically. (Did the computer start Windows or macOS
again? Read [Start your computer from the USB stick](start-from-usb.md).)

:::warning The installer erases the drive
The installer erases all data on the drive that you select, with Windows or
macOS and all files on it. Back up your files first. To keep Windows, use
[wootc](https://tunaos.org/wootc) instead.
:::

## Part 1: Install to the drive

### Step 1 — Welcome

The welcome screen shows the name of your image and gives you three options:

- **Install**: start the installation.
- **Try**: close the installer and use TunaOS from the USB stick first. To
  install later, open the installer from the desktop.
- **Accessibility**: open the accessibility settings.

### Step 2 — Select the drive

Select the drive for TunaOS. The installer uses the full drive. It does not
keep other systems or partitions on it.

#### Encryption

Set **Encrypt this disk** to on to protect your files with a passphrase.
The installer asks for the passphrase two times.

If your computer has a TPM 2.0 chip, you can also set **TPM unlock** to on.
The computer then unlocks the drive automatically at each start, and you do
not type the passphrase each time. TPM unlock needs encryption.

#### File system

The installer selects a file system for you. Keep the default if you are
not sure.

| Image | File systems | Default |
|---|---|---|
| Albacore, Skipjack | XFS, ext4 | XFS |
| Yellowfin, Bonito | XFS, Btrfs, Btrfs (subvolumes), ext4 | Btrfs (subvolumes) |

### Step 3 — Confirm

Examine the drive and the options, then confirm. This is the last step
where you can go back. After this step, the installer erases the drive.

### Step 4 — Wait for the installation

The screen shows the progress. The installation usually takes 5 to 15
minutes. The computer must stay on the internet during this step.

### Step 5 — Done

The installer asks you to restart. Remove the USB stick when the screen
goes dark.

## Part 2: First setup

TunaOS starts from the drive. First Setup opens one time and asks for:

1. **Language**.
2. **Keyboard layout**.
3. **Time zone**.
4. **Computer name**, the name of the computer on your network, for example
   `james-laptop`.
5. **User account**: your full name, a user name and a password.
6. **Theme**: light or dark.
7. **Applications**: more applications from Flathub, if you want them.

First Setup then installs the applications that you selected. This can
take some minutes. Then your desktop opens.

## Recovery key

If you set encryption to on, the installer shows a **recovery key** after
the installation. Keep the key in a safe place. The key unlocks your drive
if you forget the passphrase, or if TPM unlock does not work.

## After the installation

- Get more applications from the **Software** application (Flathub).
- TunaOS gets each update as a full new system. The computer keeps the
  previous version too. If an update causes a problem, see
  [Rollback and updates](bootc-rollback.md).
- To change the desktop or the image later, see the [FAQ](faq.md).

## Problems

### The installer does not open

Make sure that the computer started from the **UEFI** entry of the USB
stick. TunaOS does not start in the old "Legacy" or "CSM" mode. See
[Start your computer from the USB stick](start-from-usb.md).

### The installer shows no drives

The installer shows full drives only, not partitions. In a virtual machine,
add a virtual disk first.

### The installation stops or fails

- Make sure that the internet connection works. The installer downloads
  part of TunaOS during the installation.
- Make sure that the drive has 20 GB or more.
- Look for your problem in
  [GitHub Issues](https://github.com/tuna-os/tunaOS/issues), or ask in the
  [Matrix chat](https://matrix.to/#/%23tunaos:reilly.asia).

### TPM unlock stops after a Secure Boot change

TPM unlock uses the Secure Boot settings from the time of the installation.
If you change the Secure Boot settings, enroll the TPM again:

```bash
sudo systemd-cryptenroll --tpm2-device=auto --wipe-slot=tpm2 /dev/your-disk
```

## For developers

TunaOS installs with **bootc-installer**. There is one installer frontend
for each desktop, in the toolkit of that desktop. GNOME uses GTK4 and
Libadwaita, KDE uses Qt Widgets, COSMIC uses Iced, Niri uses a TUI and XFCE
uses GTK3.
All frontends use the same `fisherman` backend, which runs
`bootc install to-disk`. The live session sets the `tunaos.live=1` kernel
argument, and the installer starts when it finds that argument.

Each week, a smoke test starts each frontend in QEMU and moves through it.
It makes a screenshot at each step and reads the screen with OCR to make
sure the step is correct. These are the captures:
