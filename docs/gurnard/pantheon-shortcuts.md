# Pantheon keyboard shortcuts

Gurnard uses the Pantheon desktop from elementary OS. These shortcuts are
different from GNOME's defaults. You can change them in **System Settings →
Keyboard → Shortcuts**. On a Mac keyboard, `⌘` means the **Super** key; on most
PC keyboards it is the Windows key.

## Window management

| Shortcut | Action |
| --- | --- |
| `Alt` + `Tab` | Cycle through open windows |
| `Alt` + `F7` | Move the active window with the pointer |
| `Alt` + `F8` | Resize the active window with the pointer |
| `⌘` + `↓` | Open Multitasking View (window and workspace overview) |
| `⌘` + `←` / `→` | Move to the previous or next workspace |
| `⌘` + `1` … `9` | Jump to a numbered workspace |
| `⌘` + `0` | Create or jump to a new workspace |
| `⌘` + `Alt` + `←` / `→` | Move the active window to the previous or next workspace |

To maximize a window, drag its header bar to the top of the screen, or
double-click the header bar. You can change the window and workspace shortcuts
in **System Settings → Keyboard → Shortcuts → Workspaces**.

## Applications

| Shortcut or action | Result |
| --- | --- |
| Press `⌘`, then type | Open the Applications Menu and search for an app or setting |
| Press `⌘`, then search for **Shortcuts** | Open the desktop shortcut overlay |
| Click an app in the Dock | Focus the app, or launch it if it is not running |

Pantheon has no default shortcut that opens Gedit or Terminal. Search for
either app from the Applications Menu, or add a custom shortcut in **System
Settings → Keyboard → Shortcuts**. Gurnard images can also ship different app
names: an image may provide elementary's **Code** editor instead of Gedit.

`⌘` + `Space` is not a universal shortcut for apps in Pantheon. On elementary
defaults, this combination often changes the keyboard layout. Check **System
Settings → Keyboard → Layout** first.

## Notifications and indicators

The elementary shortcut list has no default shortcut for notifications. Select
the notification/system-indicator area on the right side of the Panel to view
notifications and related controls, including Do Not Disturb when available.

## Finding and changing shortcuts

Press `⌘` to open the Applications Menu, search for **Shortcuts**, and open the
first matching result. From the shortcut overlay, choose **Keyboard Settings**
to view or change desktop shortcuts. The same settings are available under
**System Settings → Keyboard → Shortcuts**.

Shortcut behavior can vary with the keyboard layout, connected hardware, and
Pantheon version. The local shortcut overlay is authoritative for the Gurnard
image.
