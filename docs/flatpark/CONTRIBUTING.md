All documentation lives in [`docs/`](https://github.com/tuna-os/flatpark/blob/main/docs/README.md), and the site renders the
same files at [https://flatpark.org/docs/](https://flatpark.org/docs/).

- Adding an app: [submitting an app](https://github.com/tuna-os/flatpark/blob/main/docs/packagers/submitting.md)
- The end-to-end packaging process: [packaging playbook](https://github.com/tuna-os/flatpark/blob/main/docs/packagers/playbook.md)
- How PRs are reviewed: [review runbook](https://github.com/tuna-os/flatpark/blob/main/docs/reviewers/review-runbook.md)

Onboarding is meant to run through an AI agent: open this repo in your agent
(e.g. Claude Code) and ask it to publish an app, starting from
[`docs/README.md`](https://github.com/tuna-os/flatpark/blob/main/docs/README.md).
