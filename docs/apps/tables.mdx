# 🧮 Tables

Pure Rust GTK4 spreadsheet application powered by [ironcalc_base](https://github.com/ironcalc/IronCalc), no Python or WebKit required.

Reads and writes CSV, XLSX, XLS, and ODS files.

## Install

<CodeBlock language="bash">
  flatpak remote-add --if-not-exists tuna-os https://tunaos.org/flatpak/tuna-os.flatpakrepo
  flatpak install tuna-os org.tunaos.tables-rust
</CodeBlock>

## Features

- **Formulas**: 83 functions via ironcalc_base, with live Sum/Avg/Count range statistics
- **Multi-sheet**: workbook tabs with rename/delete/reorder and Ctrl+PgUp/PgDn navigation
- **Formatting**: Bold, Italic, Underline, Alignment, Borders, conditional formatting
- **Fill handle**: drag-to-copy with series detection and relative formula shifting
- **Sort & Filter**: Column headers with sort arrows and row filtering
- **Data tools**: Merge cells, freeze panes, named ranges, print area, number formatting
- **Keyboard shortcuts**: Excel-compatible (Ctrl+B/I/U, Ctrl+D/R, Ctrl+Space, etc.)
