# 🎬 Decks

Pure Rust GTK4 presentation application with native canvas editing, no Python or WebKit required.

Reads and writes PPTX and ODP files. Exports to multi-page PDF.

## Install

<CodeBlock language="bash">
  flatpak remote-add --if-not-exists tuna-os https://tunaos.org/flatpak/tuna-os.flatpakrepo
  flatpak install tuna-os org.tunaos.decks-rust
</CodeBlock>

## Features

- **Canvas editing**: Text boxes, shapes, images on a native GTK canvas with undo/redo
- **Slide management**: Live thumbnails, master slides read from PPTX, sidebar thumbnail strip
- **Object inspector**: Per-object properties and a presenter pill
- **Present mode**: Fullscreen with fit-to-viewport scaling and keyboard navigation
- **Command palette**: Ctrl+K searchable actions
- **Export**: Multi-page PDF
