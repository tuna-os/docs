# 📄 Letters

Pure Rust GTK4 word processor for the GNOME desktop, no Python or WebKit required.

Reads and writes DOCX and ODT natively, and Markdown with CommonMark-faithful round-trips via [pulldown-cmark](https://github.com/pulldown-cmark/pulldown-cmark).

## Install

<CodeBlock language="bash">
  flatpak remote-add --if-not-exists tuna-os https://tunaos.org/flatpak/tuna-os.flatpakrepo
  flatpak install tuna-os org.tunaos.letters-rust
</CodeBlock>

## Features

- **Rich formatting**: Bold, Italic, Underline, headings, lists, footnotes
- **Multi-format I/O**: Native DOCX and ODT read/write, Markdown round-trips
- **Find & Replace**: Ctrl+F / Ctrl+H
- **Autosave + recovery**: Configurable autosave, crash recovery, atomic writes
- **Command palette**: Ctrl+K searchable actions
- **Word count**: Live status bar
- **Keyboard shortcuts**: Docs/Word-compatible
