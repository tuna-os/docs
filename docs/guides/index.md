---
title: Deployment and Development Guides
---

TunaOS ships thirteen guides. Each one covers a use case. Pick the guide that
matches your work, from local development to fleet deployment.

## Development

- [AI & ML quick-start](guides/AI-DEVELOPMENT-QUICKSTART) — Build a local base for language models and container training.
- [Game development quick-start](guides/GAMEDEV-QUICKSTART) — Run Godot, Blender, and Krita as Flatpaks, and build games in a container.
- [Kernel developer quick-start](guides/KERNEL-DEVELOPER-QUICKSTART) — Build and boot a kernel on a stable host, and roll it back on failure.
- [Linux audio and creative workstation](guides/linux-audio-creative-bootc) — Set up low-latency audio, and run audio and video tools as Flatpaks.
- [Linux gaming setup](guides/linux-gaming-bootc) — Install Steam and other clients, and roll back a bad driver update.

## Deployment

- [Enterprise remote work and thin clients](guides/ENTERPRISE-VDI-DEPLOYMENT) — Ship a stateless image to remote machines, and update the fleet from one registry.
- [Educational computer lab](guides/EDU-LAB-DEPLOYMENT) — Update many lab machines from one place, and reset student sessions on reboot.
- [Digital signage and kiosk fleets](guides/DIGITAL-SIGNAGE-KIOSK-DEPLOYMENT) — Push a new image tag, and every screen takes it on its next update.
- [IoT edge gateway](guides/INDUSTRIAL-IOT-EDGE-DEPLOYMENT) — Take OTA updates as image layers, and run workloads as isolated containers.
- [Public library terminal](guides/PUBLIC-LIBRARY-DEPLOYMENT) — Put the terminal back to a known state, and reset sessions on logout.
- [Retail point of sale terminal](guides/RETAIL-POS-DEPLOYMENT) — Keep the base read-only, add rules for peripherals, and run the app in a container.

## Administration

- [Security workstation and lab](guides/SECURITY-WORKSTATION-QUICKSTART) — Roll back to the prior image, and run tools in isolated containers.
- [Ephemeral session reset](guides/EPHEMERAL-SESSION-RESET) — End a session on inactivity, and clear user state on logout.
